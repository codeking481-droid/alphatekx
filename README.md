# AlphaTekx Video Editor

A simple, clean video editor built with Next.js 14 and Tailwind CSS.

## Features

- Drag and drop multiple videos
- Grid preview with thumbnails, names, and sizes
- Credit-based system (10 credits per video)
- Plan-based limits (Free: 3 videos, Pro: 10 videos)
- Dark, minimal UI

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the application.

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- TypeScript
