✨ KEY FEATURES

✅ REAL VIDEO GENERATION
   • Downloads real MP4 clips from Pexels (not AI-generated stubs)
   • Generates real scripts with Groq LLM
   • Creates real voices with ElevenLabs (or gTTS fallback)
   • Professional editing with FFmpeg

✅ STATE PERSISTENCE
   • Saves progress to state.json after each scene
   • Continues from checkpoint on server restart
   • No data loss, no wasted processing
   • Example: Crash at scene 12 → Resume at scene 12

✅ GRACEFUL DEGRADATION
   • ElevenLabs down → gTTS voice → silent audio
   • Pexels rate limited → blank/black clip
   • FFmpeg zoom fails → simple scale
   • API key wrong → clear error message with retry count

✅ PROFESSIONAL RESULTS
   • MrBeast-style zoom: Smooth linear (1.0→1.2)

   • Duration: Exact (each scene trimmed precisely)

📝 QUICK START (5 MINUTES)
════════════════════════════════════════════════════════════════════════════

1. SET API KEYS:
   export GROQ_API_KEY="your-key"
   export PEXELS_API_KEY_1="your-key"
   export ELEVENLABS_API_KEY="your-key"

2. START SERVER:
   npm run dev

3. GENERATE VIDEO:
   curl -X POST http://localhost:3001/api/alpha/video-stream \
     -H "Content-Type: application/json" \
     -d '{"prompt":"amazing story","plan":"free"}'

4. WATCH PROGRESS:
   📝 Script: Generating...
   🎙️ Narration: Creating voices...
   🔍 Search: Downloading clips...
   ✂️ Editing: Applying effects...
   🎬 Final: Combining video...

5. DOWNLOAD:
   Look for SSE event with finalVideoUrl
